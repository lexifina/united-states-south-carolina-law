# 42-1-590 Compensability of injuries to illegally employed minor.
When an employer and employee have accepted the provisions of this title, any injury to a minor while employed contrary to the laws of this State shall be compensable under this title the same, and to the same extent, as if such minor employee was an adult.
HISTORY: 1962 Code SECTION 72-129; 1952 Code SECTION 72-129; 1942 Code SECTION 7035-11; 1936 (39) 1231.
