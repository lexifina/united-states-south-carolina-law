# 10-11-140 Permission to use State House grounds.
Nothing contained in this article shall be construed to abridge the authority of the Department of Administration to grant permission to use the State House grounds for educational, electrical decorations, and similar purposes.
HISTORY: 1962 Code SECTION 1-424; 1952 Code SECTION 1-412; 1942 Code SECTION 1195; 1932 Code SECTION 1195; 1931 (37) 150; 1959 (51) 60; 2014 Act No. 121 (S.22), Pt V, SECTION 7.Q, eff July 1, 2015.
