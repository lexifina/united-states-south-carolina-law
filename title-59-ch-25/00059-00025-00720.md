# 59-25-720 Complaint filed with county board.
Such teacher may at any time, during the period for which he has been employed, file with the county board of education of the county in which the school is located a complaint in writing which shall set forth briefly the manner and method by which the alleged discrimination is claimed to have occurred. Any number of teachers that are employed by the same school district may join in the filing of a complaint.
HISTORY: 1962 Code SECTION 21-382; 1952 Code SECTION 21-382; 1947 (45) 110.
