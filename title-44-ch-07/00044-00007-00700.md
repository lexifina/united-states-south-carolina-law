# 44-7-700 Compensation of treasurer and trustees.
The treasurer shall receive no compensation for his services, and no trustee shall receive compensation for his services, but he may receive reimbursement for any cash expenditures actually made for personal expenses incurred as such trustee.
HISTORY: 1962 Code SECTION 32-811; 1952 Code SECTION 32-811; 1942 Code SECTION 5143; 1932 Code SECTION 5143; 1925 (34) 239.
