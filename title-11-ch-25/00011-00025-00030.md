# 11-25-30 Approval of state printing.
The Department of Administration may pass upon and approve all printing pertaining to state matters in this State except for legislative printing and printing otherwise provided by law.
HISTORY: 1962 Code SECTION 1-503; 1952 Code SECTION 1-503; 1942 Code SECTION 2090-3; 1935 (39) 83; 1950 (46) 3605; 1985 Act No. 201, Part II, SECTION 81D.
