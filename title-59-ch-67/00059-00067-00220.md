# 59-67-220 Filling gasoline tank while engine is running or pupils are on bus prohibited.
No gasoline tank on or in any vehicle used as a school bus shall be filled while the engine is running or, except in an emergency, when there are pupils in the bus.
HISTORY: 1962 Code SECTION 21-814; 1952 Code SECTION 21-814; 1942 Code SECTION 1626-3; 1937 (40) 367.
