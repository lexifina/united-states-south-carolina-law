# 48-33-80 Access to property.
The State Commission of Forestry and any of its authorized agents may, at any or all times, go upon any land for the purpose of preventing or controlling forest fires, as defined herein, without making themselves liable for trespassing.
HISTORY: 1962 Code SECTION 29-58; 1952 Code SECTION 29-58; 1945 (44) 138; 2026 Act No. 107 (H.3629), SECTION 5, eff March 30, 2026.
