# 49-19-1460 Construction and enlargement of bridges.
All bridges constructed under the provisions of this chapter and all enlargements of bridges already in existence shall be built and enlarged according to and in compliance with the plans, specifications and orders made or approved by the chief engineer of the district.
HISTORY: 1962 Code SECTION 18-526; 1952 Code SECTION 18-526; 1942 Code SECTION 6186; 1932 Code SECTION 6186; Civ. C. '22 SECTION 3240; 1920 (31) 663.
