# 57-5-40 State highway secondary system.
The state highway secondary system shall consist of all roads, streets and highways in the state highway system not otherwise designated as highways in the interstate system or the state highway primary system.
HISTORY: 1962 Code SECTION 33-104; 1952 Code SECTION 33-104; 1951 (47) 457; 1967 (55) 207; 1993 Act No. 181, SECTION 1509.
