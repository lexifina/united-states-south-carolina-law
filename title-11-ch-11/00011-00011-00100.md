# 11-11-100 General Assembly may amend budget bill.
The General Assembly may increase or decrease items in the budget bill as it may deem to be in the interest of greater economy and efficiency in the public service.
HISTORY: 1962 Code SECTION 1-730; 1952 Code SECTION 1-730; 1942 Code SECTION 3221; 1932 Code SECTION 3221; Civ. C. '22 SECTION 917; 1919 (31) 187.
