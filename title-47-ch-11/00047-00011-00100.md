# 47-11-100 Tuberculosis and paratuberculosis tests required for all animals except those for immediate slaughter.
All animals except those for immediate slaughter must be tested for tuberculosis and paratuberculosis when considered advisable by the commission before they are released from the stockyards.
HISTORY: 1962 Code SECTION 6-340; 1952 Code SECTION 6-340; 1950 (46) 2346; 1994 Act No. 362, SECTION 5, eff May 3, 1994.
