# 50-1-140 Receiving portion of fine imposed for violation of game and fish laws.
It shall be unlawful for any enforcement officer or any person to receive any portion of a fine imposed by any court for the violation of the game and fish laws of the State.
HISTORY: 1962 Code SECTION 28-12; 1952 Code SECTION 28-12; 1942 Code SECTION 1766; 1934 (38) 1415; 1952 (47) 2179; 1993 Act No. 181, SECTION 1257.
