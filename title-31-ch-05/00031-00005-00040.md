# 31-5-40 Conveyances authorized by SECTION 31-5-30; appraisals, public notices, etc.
Any law or statute to the contrary notwithstanding, any sale, conveyance, lease or agreement authorized by SECTION 31-5-30 may be made by a State public body without appraisal, public notice, advertisement or public bidding.
HISTORY: 1962 Code SECTION 36-304; 1952 Code SECTION 36-304; 1942 Code SECTION 5271-74; 1939 (41) 320; 1945 (44) 156.
