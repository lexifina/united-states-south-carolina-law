# 15-39-840 Conveyances of real estate sold under execution.
When any sheriff or other officer makes a conveyance of any real estate sold by virtue of a tax execution or other execution the conveyance shall contain the name of the person owning the property executed on, the name of the judgment creditor executing, the date of execution and the date of sale.
HISTORY: 1962 Code SECTION 10-1787; 1952 Code SECTION 10-1787; 1942 Code SECTION 9083; 1932 Code SECTION 9079; 1929 (36) 277.
