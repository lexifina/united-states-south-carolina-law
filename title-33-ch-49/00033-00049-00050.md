# 33-49-50 Exemption from control of Public Service Commission.
Cooperatives and foreign corporations transacting business in this State pursuant to this chapter, except for the provisions of Sections 58-27-40, 58-27-610 through 58-27-670, 58-27-820, 58-27-840, 58-27-1210, 58-27-1270, 58-27-1280, 58-27-210, and 33-49-150 are exempt from the jurisdiction and control of the Public Service Commission of this State.
HISTORY: 1962 Code SECTION 12-1005; 1952 Code SECTION 12-1005; 1942 Code SECTION 8555-119; 1939 (41) 240; 1969 (56) 740; 2019 Act No. 56 (H.3145), SECTION 1, eff January 1, 2020.
