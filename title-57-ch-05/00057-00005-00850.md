# 57-5-850 Source of funds for system.
The State highway system shall be built, constructed and maintained from any moneys derived from the automobile license tax, gasoline tax and other special imposts upon highway users, Federal aid and other grants-in-aid and such other moneys as may from time to time be made available.
HISTORY: 1962 Code SECTION 33-176; 1952 Code SECTION 33-176; 1951 (47) 457.
