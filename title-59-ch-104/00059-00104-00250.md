# 59-104-250 Technical college libraries shall convert to computer-based automated system compatible with state library systems.
All libraries in the technical colleges in this State shall convert to a computer-based automated system that is compatible with existing state library systems and allows for appropriate networking with public colleges and universities if funds are appropriated for this purpose. The Commission on Higher Education shall request special appropriations to accomplish the conversion.
HISTORY: 1988 Act No. 629, SECTION 1; 1996 Act No. 359, SECTION 10.
