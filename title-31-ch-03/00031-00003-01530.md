# 31-3-1530 Agreement limiting powers in connection with governmental loans or grants.
In connection with any loan or grant by a government, an authority may agree to limitations upon the exercise of any powers conferred upon the authority by this chapter and Chapter 11.
HISTORY: 1962 Code SECTION 36-153; 1952 Code SECTION 36-153; 1942 Code SECTION 5271-39; 1934 (38) 1368.
