# 59-21-730 Payment of State aid; amount.
State aid for school psychologists shall be paid from the appropriation for State aid for teachers salaries. The amount of State aid for each psychologist employed shall be determined by the application of the same laws, rules and regulations as pertain to the existing State scale for paying teachers' salaries.
HISTORY: 1962 Code SECTION 21-295.23; 1962 (52) 1896.
