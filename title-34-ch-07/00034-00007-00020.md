# 34-7-20 Effect of reorganization plan on claims of depositors and unsecured creditors.
Any such reorganization plan may authorize the reduction of the claims of depositors and unsecured creditors, postpone the payment thereof or provide for such payment in installments as will appear to be to the best interest of the parties interested. In any such plan all claims or demands of the same class shall be treated alike.
HISTORY: 1962 Code SECTION 8-312; 1952 Code SECTION 8-312; 1942 Code SECTION 7874; 1932 (37) 1183.
