# 49-19-1080 Appeal.
Any person or party aggrieved may appeal the final judgment of the circuit court in the manner provided by the South Carolina Appellate Court Rules.
HISTORY: 1962 Code SECTION 18-488; 1952 Code SECTION 18-488; 1942 Code SECTION 6171; 1932 Code SECTION 6171; Civ. C. '22 SECTION 3225; 1920 (31) 663; 1999 Act No. 55, SECTION 47.
