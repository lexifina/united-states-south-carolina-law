# 11-5-150 Monies appropriated for erection of state college buildings.
All monies appropriated to provide buildings for any of the state colleges shall remain in the State Treasury until they shall be needed for the actual erection of the respective buildings for which the appropriations are made.
HISTORY: 1962 Code SECTION 1-859; 1952 Code SECTION 1-859; 1942 Code SECTION 3201; 1932 Code SECTION 3201; Civ. C. '22 SECTION 898; Civ. C. '12 SECTION 818; 1909 (26) 282.
