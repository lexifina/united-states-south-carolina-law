# 50-1-70 Application of game laws to zones.
All laws of this State in force on April 24, 1952, affecting game shall, until changed, apply to all of the zones of the State, and all laws of the State thereafter enacted shall apply to the entire State except where otherwise specified.
HISTORY: 1962 Code SECTION 28-6; 1952 (47) 2179; 1993 Act No. 181, SECTION 1257.
