# 57-5-60 Permitted additions to primary system.
The department may add to the state highway primary system any sections or connections which, in the judgment of the department may be necessary in the proper development of the federal-aid primary highway system or the state highway primary system.
HISTORY: 1962 Code SECTION 33-106; 1952 Code SECTION 33-106; 1951 (47) 457; 1993 Act No. 181, SECTION 1509.
