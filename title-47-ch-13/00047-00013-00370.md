# 47-13-370 Blank forms used to certify test results.
The State Veterinarian shall, upon request, furnish to the persons needing them, suitable blank forms to be used in certifying the result of any test made under the provisions of Section 47-13-360.
HISTORY: 1962 Code SECTION 6-427; 1952 Code SECTION 6-427; 1948 (45) 1888.
