# 39-19-440 Delivery records must be kept by warehouseman or cooperative.
Any such warehouseman or cooperative marketing association shall keep a record of such purchase or delivery showing the quantity of leaf tobacco so delivered, the name of the owner thereof given as provided in Section 39-19-430, the name of the person from whom the person other than the producer or landlord on whose land the tobacco was produced obtained it and the name of the landlord on whose land it was produced.
HISTORY: 1962 Code SECTION 69-42; 1952 Code SECTION 69-42; 1942 Code SECTION 7204; 1932 Code SECTION 7204; 1924 (33) 993.
