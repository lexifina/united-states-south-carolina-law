# 11-7-10 Selection; assistants.
The State Fiscal Accountability Authority shall select the State Auditor, who shall select necessary assistants in conformity with the appropriations for the office.
HISTORY: 1962 Code SECTION 1-881; 1952 Code SECTION 1-881; 1942 Code SECTION 3222-1; 1933 (38) 297; 1950 (46) 2353; 2005 Act No. 164, SECTION 1; 2014 Act No. 121 (S.22), Pt V, SECTION 7.S.1, eff July 1, 2015.
