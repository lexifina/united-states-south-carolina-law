# 2-7-70 Itemization of appropriation bills.
All bills introduced in either house carrying appropriations shall be itemized in accordance with the classifications used in the budget.
HISTORY: 1962 Code SECTION 30-206; 1952 Code SECTION 30-206; 1942 Code SECTION 3221; 1932 Code SECTION 3221; Civ. C. '22 SECTION 917; 1919 (31) 187.
