# 58-15-1730 Continuance of crossings as private crossings.
All existing grade crossings replaced by grade separation structures or avoided by relocation of highways and no longer habitually used by the general public may be continued only as private crossings and not subject to the provisions of the statutes of this State relating to railroad crossings.
HISTORY: 1962 Code SECTION 58-824; 1952 Code SECTION 58-824; 1942 Code SECTION 8466; 1932 Code SECTION 8441; 1924 (33) 1057.
