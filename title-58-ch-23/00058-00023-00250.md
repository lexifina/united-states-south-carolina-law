# 58-23-250 Class D certificates.
The Office of Regulatory Staff, upon directive of the commission, may issue a certificate D for property-carrying vehicles which will operate upon regular routes and schedules over such highways.
HISTORY: 1962 Code SECTION 58-1415; 1952 Code SECTION 58-1415; 1942 Code SECTION 8510; 1932 Code SECTION 8510; 1925 (34) 252; 1930 (36) 1068; 2006 Act No. 318, SECTION 145, eff May 24, 2006; 2022 Act No. 214 (S.1045), SECTION 10, eff May 23, 2022.
