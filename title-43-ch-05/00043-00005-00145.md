# 43-5-145 Investigation of application.
Investigation of each application shall be made by the county departments as provided in Chapters 1, 3, 5, 7, 9, 19, and 23 or as required by the state department.
HISTORY: 1976 Code SECTION 43-5-20; 1962 Code SECTION 71-52; 1952 Code SECTION 71-52; 1942 Code SECTION 4996-15; 1937 (40) 496; 1978 Act No. 549; 1997 Act No. 133, SECTION 7, eff June 11, 1997.
