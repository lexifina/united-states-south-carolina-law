# 25-3-20 Governor may call State Guard into duty.
Whenever any part of the National Guard of this State is ordered into Federal service so as to cause the State to be, in the opinion of the Governor, without proper defense, the Governor may call the South Carolina State Guard into state duty.
HISTORY: 1962 Code SECTION 44-252; 1952 Code SECTION 44-252; 1950 (46) 1881; 1981 Act No. 145 SECTION 2.
