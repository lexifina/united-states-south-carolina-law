# 58-31-140 State and its subdivisions shall never levy taxes or appropriate funds for project.
It is hereby declared that the State and any of its political subdivisions shall never levy any tax to pay any obligations incurred in building this project or make any appropriation to carry on the work of developing the Santee-Cooper power project.
HISTORY: 1962 Code SECTION 59-12; 1952 Code SECTION 59-12; 1942 Code SECTION 8555-22; 1934 (38) 1507.
