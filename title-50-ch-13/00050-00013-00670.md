# 50-13-670 Possession of game fish while possessing or using nongame devices prohibited.
It is unlawful for a person to have in possession game fish, except live bream on those water bodies where permitted as live bait, while possessing or using nongame devices. The provisions of this section do not apply to a person using a cast net or landing net (dip net).
