# 38-21-150 Summary outlining changes since previous registration statement required.
All registration statements shall contain a summary outlining all items in the current registration statement representing changes from the prior registration statement.
HISTORY: Former 1976 Code SECTION 38-29-155 [1986 Act No. 426, SECTION 10] recodified as SECTION 38-21-150 by 1987 Act No. 155, SECTION 1.
