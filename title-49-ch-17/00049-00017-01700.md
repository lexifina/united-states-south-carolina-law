# 49-17-1700 Assessments of less than twenty-five dollars payable in cash.
When the original assessment for drainage purposes is less than twenty-five dollars upon a property the owner must pay it in cash so that there will be no necessity to issue bonds thereon for drainage purposes.
HISTORY: 1962 Code SECTION 18-322; 1952 Code SECTION 18-322; 1942 Code SECTION 6220; 1932 Code SECTION 6220; Civ. C. '22 SECTION 3274; 1920 (31) 1023.
