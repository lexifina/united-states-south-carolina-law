# 58-23-1020 Certain routes or schedules shall not be changed without permit from Commission.
No motor vehicle carrier holding a certificate A, B, or D shall change the route or schedule of his motor vehicle during any year for which a license has been issued without procuring an order of the commission before the route is changed.
HISTORY: 1962 Code SECTION 58-1462; 1952 Code SECTION 58-1462; 1942 Code SECTION 8513; 1932 Code SECTION 8513; 1925 (34) 252; 2022 Act No. 214 (S.1045), SECTION 20, eff May 23, 2022.
