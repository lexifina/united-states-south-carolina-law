# 59-31-300 Retention of books within districts.
As far as may be practicable the State Board of Education shall provide for the retention of all necessary schoolbooks for use by the school districts within such districts.
HISTORY: 1962 Code SECTION 21-480; 1952 Code SECTION 21-480; 1942 Code SECTION 5295; 1936 (39) 1549.
