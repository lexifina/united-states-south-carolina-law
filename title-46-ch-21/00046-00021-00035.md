# 46-21-35 Seed laboratory.
The Department of Agriculture shall maintain a seed laboratory with necessary equipment for carrying out the provisions of this chapter.
HISTORY: 1940 (41) 1875; 1941 (42) 119; 1942 Code SECTION 5806-81; 1952 Code SECTION 3-403; 1962 Code SECTION 3-403; 1976 Code SECTION 46-21-30; 2010 Act No. 238, SECTION 2, eff. upon approval (became law without the Governor's signature on June 8, 2010).
