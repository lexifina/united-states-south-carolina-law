# 40-15-230 Applicant for license to practice specialty must be licensed to practice dentistry.
Before an applicant can be licensed to practice a specialty, he must first have been licensed to practice dentistry in the State.
HISTORY: 1962 Code SECTION 56-636.23; 1952 Code SECTION 56-602; 1945 (44) 363; 1968 (55) 2502.
