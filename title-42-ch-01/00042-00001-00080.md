# 42-1-80 "Commission" defined.
The term "commission" means the South Carolina Workers' Compensation Commission created under the provisions of this title.
HISTORY: 1962 Code SECTION 72-7; 1952 Code SECTION 72-7; 1942 Code SECTION 7035-2; 1936 (39) 1231; 1986 Act No. 399, SECTION 1, eff May 6, 1986.
