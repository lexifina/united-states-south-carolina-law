# 55-3-120 Construction.
This chapter must be interpreted and construed as to effectuate its general purpose of promoting aviation, aeronautics, aviation safety, and conforming and making consistent this State's laws with federal law, and the laws of other states on the subject of aviation and aeronautics.
HISTORY: 1962 Code SECTION 2-12; 1952 Code SECTION 2-12; 1942 Code SECTION 7110; 1932 Code SECTION 7110; 1929 (36) 220; 2012 Act No. 270, SECTION 2, eff June 18, 2012.
