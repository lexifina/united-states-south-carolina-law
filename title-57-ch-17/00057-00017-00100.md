# 57-17-100 Closing certain railroad-highway crossings.
The various county authorities may, in their discretion, abandon and close to highway traffic railroad-highway crossings on highways not in the State highway system superseded by the construction of grade separation structures, the reconstruction of existing structures or the relocation of highways to eliminate such grade crossings.
HISTORY: 1962 Code SECTION 33-819; 1952 Code SECTION 33-819; 1942 Code SECTION 5866-2; 1939 (41) 334.
