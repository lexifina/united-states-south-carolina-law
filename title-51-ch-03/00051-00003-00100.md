# 51-3-100 Necessary and incidental powers of Department.
The Department of Parks, Recreation, and Tourism may in general do any and all things necessary and incident to the furtherance of the use to which such parks are dedicated.
HISTORY: 1962 Code SECTION 51-5; 1952 Code SECTION 51-5; 1942 Code SECTION 3284-2; 1934 (38) 1542.
