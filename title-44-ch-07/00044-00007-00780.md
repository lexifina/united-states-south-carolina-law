# 44-7-780 Donations.
Any person desiring to make donations of money, personal property or real estate for the benefit of any such hospital or tuberculosis camp may vest title to the property so donated in any county, township, city or town, to be controlled when accepted by the board of hospital trustees according to the terms of the deed.
HISTORY: 1962 Code SECTION 32-820; 1952 Code SECTION 32-820; 1942 Code SECTION 5145; 1932 Code SECTION 5145; 1925 (34) 239.
