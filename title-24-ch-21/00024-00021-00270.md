# 24-21-270 Offices for probation agents.
The governing body of each county in which a probation agent serves shall provide, in or near the courthouse, suitable office space for such agent.
HISTORY: 1962 Code SECTION 55-577; 1952 Code SECTION 55-577; 1942 Code SECTION 1038-15; 1942 (42) 1456; 1965 (54) 213; 1991 Act No. 134, SECTION 10.
