# 39-17-10 Declaration of purpose.
The purpose of this article is to give authority to investigate marketing conditions and to establish and maintain standard containers, grades and State brands for fresh fruits and vegetables in the State.
HISTORY: 1962 Code SECTION 66-321; 1952 Code SECTION 66-321; 1942 Code SECTION 6662; 1932 Code SECTION 6662; Civ. C. '22 SECTION 3569; 1921 (32) 264.
