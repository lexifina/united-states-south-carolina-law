# 59-5-110 School system survey.
As soon as practicable the Board of Education, as successor to the State Educational Finance Commission, shall make a survey of the entire school system, which shall set forth the needs for new construction, new equipment, new transportation facilities and such other improvements as are necessary to enable all children of the State to have adequate and equal educational advantages.
HISTORY: 1962 Code SECTION 21-57; 1952 Code SECTION 21-57; 1951 (47) 546.
