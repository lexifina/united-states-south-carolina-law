# 58-23-280 Provisions governing class A and C certificates shall apply to D and E certificates.
The provisions of this chapter governing the granting of certificates A and C apply to certificates D and E.
HISTORY: 1962 Code SECTION 58-1418; 1952 Code SECTION 58-1418; 1942 Code SECTION 8510; 1932 Code SECTION 8510; 1925 (34) 252; 1930 (36) 1068; 2006 Act No. 318, SECTION 145, eff May 24, 2006.
