# 59-31-310 Counties required to provide depositories for books.
The various counties, through their properly constituted authorities, shall furnish a sufficient and proper place for depositing or storing books used in such counties.
HISTORY: 1962 Code SECTION 21-481; 1952 Code SECTION 21-481; 1942 Code SECTION 5289; 1936 (39) 1549.
