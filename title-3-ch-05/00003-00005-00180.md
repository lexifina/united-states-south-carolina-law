# 3-5-180 Remedies with respect to oysters beyond limits of acquired areas exclusive.
The remedies herein given with respect to oysters lying beyond the limits of the areas to be acquired for said waterway project such rights of way shall be exclusive.
HISTORY: 1962 Code SECTION 70-267; 1952 Code SECTION 70-267; 1942 Code SECTION 6031-4; 1934 (38) 1314; 2026 Act No. 146 (H.4189), SECTION 7, eff May 15, 2026.
