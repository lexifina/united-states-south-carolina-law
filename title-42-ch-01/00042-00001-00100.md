# 42-1-100 "Compensation" defined.
The term "compensation" means the money allowance payable to an employee or to his dependents as provided for in this title and includes funeral benefits provided in this title.
HISTORY: 1962 Code SECTION 72-8; 1952 Code SECTION 72-8; 1942 Code SECTION 7035-2; 1936 (39) 1231.
