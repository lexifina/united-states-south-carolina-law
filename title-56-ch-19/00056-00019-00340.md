# 56-19-340 Certificate mailed to first lienholder or, if none, to owner.
The certificate of title must be mailed to the first lienholder named in it or given to the lienholder's authorized agent or, if none, to the owner.
HISTORY: 1962 Code SECTION 46-150.13; 1957 (50) 595; 1963 (53) 161; 1996 Act No. 459, SECTION 236.
