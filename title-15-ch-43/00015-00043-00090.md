# 15-43-90 Use of proceeds of sale of personal property.
The proceeds of the sale of the personal property, as provided in SECTION 15-43-80, shall be applied in the payment of the costs of the action and abatement, and the balance, if any, shall be paid to the defendant.
HISTORY: 1962 Code SECTION 10-1809; 1952 Code SECTION 10-1809; 1942 Code SECTION 580; 1932 Code SECTION 580; Civ. P. '22 SECTION 496; 1918 (30) 816.
