# 60-1-90 Administration of state and federal grants to public libraries; eligibility for grants.
Any public library which accepts state and federal grants administered by the South Carolina State Library may not use the grants to replace local funding for the library. In order to qualify for grants, libraries shall meet maintenance of effort requirements set by the State Library Board in accord with state and federal regulations.
HISTORY: 1985 Act No. 178, SECTION 2.
