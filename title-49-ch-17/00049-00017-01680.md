# 49-17-1680 Correction of assessment books.
The county auditor shall make the original and duplicate assessment book conform each year with such report and changes.
HISTORY: 1962 Code SECTION 18-319; 1952 Code SECTION 18-319; 1942 Code SECTION 6219; 1932 Code SECTION 6219; Civ. C. '22 SECTION 3273; 1920 (31) 1023.
