# 32-1-260 Association and corporate charters amended to confer powers set out in SECTION 32-1-250.
The charters of all associations or corporations incorporated under the laws of this State are hereby amended so as to confer upon them the rights and powers conferred and established by SECTION 32-1-250.
HISTORY: 1962 Code SECTION 11-65.1; 1952 Code SECTION 11-65.1; 1942 Code SECTION 6321; 1932 Code SECTION 6321; 1928 (35) 1228.
