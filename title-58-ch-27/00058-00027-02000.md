# 58-27-2000 Administration of oaths; examination of witnesses; certification of official acts.
For the purposes mentioned in this chapter, commissioners may administer oaths, examine witnesses, consistent with the Code of Judicial Conduct, and certify official acts.
HISTORY: 1962 Code SECTION 24-140; 1952 Code SECTION 24-140; 1942 Code SECTION 8555-5; 1932 (37) 1497; 2006 Act No. 318, SECTION 206, eff May 24, 2006.
