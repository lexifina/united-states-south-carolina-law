# 25-13-130 Records shall be turned over to Comptroller General.
All records in regard to pensioners shall be immediately turned over to the Comptroller General of the State by those who come into control or possession thereof.
HISTORY: 1962 Code SECTION 44-564; 1952 Code SECTION 44-564; 1942 Code SECTION 4985; 1932 Code SECTION 4985; 1929 (36) 176.
