# 39-7-50 Exemptions.
This chapter shall not apply to any contract or agreement between producers, between wholesalers or between retailers as to the sale or resale prices.
HISTORY: 1962 Code SECTION 66-95; 1952 Code SECTION 66-95; 1942 Code SECTION 6639; 1937 (40) 301.
Validity
For the validity of this section, see Rogers-Kent, Inc. v. General Electric Co., 231 S.C. 636, 99 S.E.2d 665 (1957).
