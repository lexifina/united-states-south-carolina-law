# 38-77-210 Uninsured motorist provision not required to cover property damages paid to insured.
The uninsured motorist provision need not insure any liability for property damages for which loss a policyholder has been compensated by insurance or otherwise.
HISTORY: Former 1976 Code SECTION 56-9-890 [1962 Code SECTION 46-750.38; 1963 (53) 526] recodified as SECTION 38-77-210 by 1987 Act No. 155, SECTION 1.
