# 39-7-20 Definitions.
The following terms, as used in this chapter are defined as follows:
(1) "Commodity" means any subject of commerce;
(2) "Producer" means any grower, baker, maker, manufacturer, bottler, packer, converter, processor or publisher;
(3) "Wholesaler" means any person selling a commodity other than a producer or retailer; and
(4) "Retailer" means any person selling a commodity to consumers for use.
HISTORY: 1962 Code SECTION 66-92; 1952 Code SECTION 66-92; 1942 Code SECTION 6639; 1937 (40) 301.
Validity
For the validity of this section, see Rogers-Kent, Inc. v. General Electric Co., 231 S.C. 636, 99 S.E.2d 665 (1957).
