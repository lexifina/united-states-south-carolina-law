# 45-7-50 Revocation of license.
The governing body of any county wherein such a license has been issued may, upon such showing as to it may seem proper, revoke any license issued under the terms of this chapter.
HISTORY: 1962 Code SECTION 35-205; 1952 Code SECTION 35-205; 1942 Code SECTION 5123-4; 1937 (40) 172.
