# 24-21-240 Oath of probation agents.
Each person appointed as a probation agent must take an oath of office as required of state officers which must be noted of record by the clerk of court.
HISTORY: 1962 Code SECTION 55-574; 1952 Code SECTION 55-574; 1942 Code SECTION 1038-8; 1942 (42) 1456; 1991 Act No. 134, SECTION 7.
