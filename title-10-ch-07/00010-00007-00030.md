# 10-7-30 Insurance on public buildings of counties.
All insurance on public buildings and the contents thereof of the several counties shall be carried by the State Fiscal Accountability Authority.
HISTORY: 1962 Code SECTION 1-432; 1952 Code SECTION 1-432; 1942 Code SECTION 2181; 1936 (39) 1668; 1950 (46) 3605.
