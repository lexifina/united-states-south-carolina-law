# 59-53-1820 Board authorized to cooperate with local or State agencies for educational advancement.
The State Board of Career and Technology Training may cooperate with any local or state agency for the advancement of agricultural and industrial education.
HISTORY: 1962 Code SECTION 21-692; 1952 Code SECTION 21-692; 1942 Code SECTION 5395; 1932 Code SECTION 5284; Civ. C. '22 SECTION 2544; 1917 (30) 42; 2005 Act No. 49, SECTION 16, eff May 3, 2005.
