# 48-23-40 Payment of commission members' expenses.
The members of the Commission shall be paid their actual expenses while in attendance upon the meetings of the Commission or while going to and from such meetings.
HISTORY: 1962 Code SECTION 29-4; 1952 Code SECTION 29-4; 1942 Code SECTION 3278; 1932 Code SECTION 3278; 1927 (35) 367.
