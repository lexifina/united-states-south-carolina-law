# 27-39-270 Property removed from premises.
Any property belonging to the tenant removed from the premises shall, if found, be subject to distraint and sale, provided such distraint be made within thirty days after such removal.
HISTORY: 1962 Code SECTION 41-156; 1952 Code SECTION 41-156; 1946 (44) 2584; 1960 (51) 1602.
