# 58-15-1620 Application of article.
The provisions of this article shall apply throughout the State to the elimination of grade crossings, whether such elimination be made upon the order or request of the State Highway Commission, counties, cities, drainage districts or other subdivisions or departments of the State government.
HISTORY: 1962 Code SECTION 58-812; 1952 Code SECTION 58-812; 1942 Code SECTION 8462; 1932 Code SECTION 8437; 1924 (33) 1057.
