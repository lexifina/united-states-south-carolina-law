# 42-1-170 "Parent" defined.
The term "parent" includes stepparents and parents by adoption, parents-in-law and any person who for more than three years prior to the death of the deceased employee stood in the place of a parent to him, if dependent on the injured employee.
HISTORY: 1962 Code SECTION 72-16; 1952 Code SECTION 72-16; 1942 Code SECTION 7035-2; 1936 (39) 1231.
