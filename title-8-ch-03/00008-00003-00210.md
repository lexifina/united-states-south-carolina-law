# 8-3-210 State officers and employees shall advise interested persons as to bonds and furnish copies.
Any officer, agent, servant or employee in any office of the State or any of its boards, bureaus, departments, commissions or other instrumentalities, upon request therefor by any interested person, shall supply such person with information as to whether any person employed in any office, board, bureau, department, commission, agency or other instrumentality of the State is bonded for any purpose and, if so, furnish such interested person with a copy of such bond.
HISTORY: 1962 Code SECTION 50-75; 1952 Code SECTION 50-75; 1942 Code SECTION 3061; 1939 (41) 335.
