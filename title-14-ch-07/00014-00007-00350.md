# 14-7-350 Term of extra or special panel.
The extra or special panel may be discharged as soon as the need for it ceases.
HISTORY: 1962 Code SECTION 38-81; 1952 Code SECTION 38-81; 1942 Code SECTION 626-3; 1936 (39) 1431; 1976 Code SECTION 14-7-420; 1986 Act No. 340, SECTION 1, eff March 10, 1986.
