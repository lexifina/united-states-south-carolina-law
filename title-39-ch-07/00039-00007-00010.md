# 39-7-10 Short title.
This chapter may be known and cited as the "Fair Trade Act."
HISTORY: 1962 Code SECTION 66-91; 1952 Code SECTION 66-91; 1942 Code SECTION 6639; 1937 (40) 301.
Validity
For the validity of this section, see Rogers-Kent, Inc. v. General Electric Co., 231 S.C. 636, 99 S.E.2d 665 (1957).
