# 44-7-730 Prerequisites to construction of hospital.
No hospital building shall be erected or constructed until plans and specifications have been made therefor and adopted by the board of hospital trustees and bids advertised for according to the law and custom in regard to other county buildings.
HISTORY: 1962 Code SECTION 32-814; 1952 Code SECTION 32-814; 1942 Code SECTION 5144; 1932 Code SECTION 5144; 1925 (34) 239.
