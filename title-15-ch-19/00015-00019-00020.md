# 15-19-20 Attachment in libel and slander actions against nonresidents or foreign corporations.
Any and all attachments issued, made or levied in any of the courts of this State of the property, goods or credits of any nonresident of this State or of any foreign corporation in actions for libel and slander, if otherwise good and valid, shall stand as if the suit had been brought upon any other cause of action mentioned in SECTION 15-19-10 or otherwise provided by the law.
HISTORY: 1962 Code SECTION 10-902; 1952 Code SECTION 10-902; 1942 Code SECTION 527-1; 1932 Code (37) 1116.
