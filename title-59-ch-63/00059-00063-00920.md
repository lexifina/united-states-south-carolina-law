# 59-63-920 School compliance and documentation.
The principal or charter school leader of each school shall comply with the requirements of Section 59-63-910 and document their compliance.
HISTORY: 1962 Code SECTION 21-872; 1952 Code SECTION 21-872; 1942 Code SECTION 5465; 1932 Code SECTION 5471; 1927 (35) 168; 2018 Act No. 256 (S.709), SECTION 3, eff July 2, 2018.
