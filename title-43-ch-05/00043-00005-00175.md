# 43-5-175 Effect of state department's decision on county department.
All decisions of the state department shall be binding upon the county department involved and shall be complied with by such county department.
HISTORY: 1976 Code SECTION 43-5-90; 1962 Code SECTION 71-59; 1952 Code SECTION 71-59; 1942 Code SECTION 4996-18; 1937 (40) 496; 1978 Act No. 549; 1997 Act No. 133, SECTION 7, eff June 11, 1997.
