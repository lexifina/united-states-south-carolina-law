# 5-25-150 Review of actions or orders of inspector by city council.
The city council may at any time review, reverse, modify or affirm any action or order given by the inspector.
HISTORY: 1962 Code SECTION 47-1175; 1952 Code SECTION 47-1175; 1942 Code SECTION 7475; 1932 Code SECTION 7475; Civ. C. '22 SECTION 4590; 1917 (30) 77.
