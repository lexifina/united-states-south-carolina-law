# 11-9-340 Statement of bonded indebtedness in Comptroller General's report.
The Comptroller General shall, as a part of his annual report, give the amount of the bonded indebtedness of the State.
HISTORY: 1962 Code SECTION 1-776; 1952 Code SECTION 1-776; 1942 Code SECTION 7340; 1932 Code SECTION 7340; 1927 (35) 260.
