# 56-5-5130 Requirements as to flares, fusees, and other warning devices.
The flares, fusees, lanterns and flags to be displayed as required in Sections 56-5-5090 to 56-5-5110 shall conform with the requirements of Section 56-5-5060 applicable thereto.
HISTORY: 1962 Code SECTION 46-628; 1952 Code SECTION 46-628; 1949 (46) 466.
