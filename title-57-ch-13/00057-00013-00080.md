# 57-13-80 Formation of bridge districts by counties.
Any two or more counties of this State desiring to construct a bridge or bridges across any of the streams of the State, whether contiguous to such counties or not, may enter into a combination and form a bridge district.
HISTORY: 1962 Code SECTION 33-609; 1952 Code SECTION 33-609; 1942 Code SECTION 5844; 1932 Code SECTION 5844; 1922 (32) 1332.
