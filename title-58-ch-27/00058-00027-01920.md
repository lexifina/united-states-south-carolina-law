# 58-27-1920 Rules governing hearings and proceedings.
All hearings and proceedings must be governed by law and by rules of practice and procedure adopted by the commission.
HISTORY: 1962 Code SECTION 24-132; 1952 Code SECTION 24-132; 1942 Code SECTION 8555-5; 1932 (37) 1497; 2006 Act No. 318, SECTION 201, eff May 24, 2006.
