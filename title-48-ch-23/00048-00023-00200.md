# 48-23-200 Rules and regulations.
The State Commission of Forestry may make such rules and regulations as it deems advisable for the protection, preservation, operation and maintenance, and for the most beneficial service to the general public, of the State forests in this State.
HISTORY: 1962 Code SECTION 29-22; 1952 Code SECTION 29-22; 1942 Code SECTION 3284-4; 1937 (40) 569.
