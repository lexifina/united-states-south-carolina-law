# 40-9-50 Filing of credentials and payment of fee.
All applicants for a license examination shall file with the secretary of the board, on or before a specified date to be determined by the board, a completed application to be provided by the board, supported by proper credentials and the payment of a fee to be set by the board.
HISTORY: 1962 Code SECTION 56-355; 1952 Code SECTION 56-355; 1942 Code SECTION 5250-3; 1932 (37) 1552; 1980 Act No. 307, SECTION 7.
