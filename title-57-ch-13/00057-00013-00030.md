# 57-13-30 Preceding sections inapplicable to certain bridges.
Sections 57-13-10 and 57-13-20 shall not apply to any bridge or crossing which does not constitute the terminus of a highway in the State highway system.
HISTORY: 1962 Code SECTION 33-603; 1952 Code SECTION 33-603; 1942 Code SECTION 6062; 1932 Code SECTION 6062; 1926 (34) 995.
