# 31-3-710 Counties empowered to create housing authorities.
In each county of the State there may be created in the manner herein provided a public body corporate and politic to be known as the housing authority of the county.
HISTORY: 1962 Code SECTION 36-181; 1952 Code SECTION 36-181; 1942 Code SECTION 5271-54; 1934 (38) 1368; 1935 (39) 500; 1937 (40) 267.
