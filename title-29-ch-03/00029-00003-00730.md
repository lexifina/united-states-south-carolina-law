# 29-3-730 Effect of failure of appraisers to agree.
If a majority of the board shall not agree and make return within the time above prescribed another shall be likewise appointed of the same qualifications and with the same duties and likewise thereafter new boards shall be appointed until one shall make a return agreed to by a majority.
HISTORY: 1962 Code SECTION 45-93; 1952 Code SECTION 45-93; 1942 Code SECTION 8712; 1933 (38) 350.
